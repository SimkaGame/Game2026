# Portal Jumper

Portal Jumper — это 2D-платформер, в котором главный герой прыгает по платформам, сражается с монстрами и ищет порталы, чтобы попасть на следующий уровень.   
Каждый новый портал переносит персонажа в другой мир с новыми врагами, ловушками и испытаниями.   
Цель — пройти все уровни.

## Релиз 1.0.0

## О проекте

Учебный проект на C#.

## Основные механики, которые планируется реализовать:
- управление персонажем (движение и атака)
- враги с простым ИИ
- система уровней через порталы
- сбор предметов / очков

## Архитектура и архитектурные решения

1. Singleton `Core/GameManager.cs`. Инкапсулирует центральную логику игры, игровой цикл, управление состояниями и загрузкой уровней. Гарантирует существование строго одного управляющего центра.
2. Decorator `Core/GameManager.cs` (методы `IsActive` / `RemoveDecorator`)*. Позволяет динамически накладывать временные эффекты на персонажа (защитный щит, ускорение ветра).
3. Adapter `Entities/TurretAdapter.cs`. Адаптирует логику стационарной турели под общий интерфейс. 
4. Command `Core/InputHandler.cs` и папку `Core/Commands/`*. Превращает действия игрока (перемещение, сохранение, загрузка) в отдельные объекты. Это позволяет легко конфигурировать ввод и избавляет от жесткой привязки к кнопкам.
5. State `Core/States/GamePlayState.cs`. Управляет текущими экранами игры (активный геймплей, пауза, экран проигрыша).

## Запуск игры

1. Разорхивируете архив в удобное место.
2. Запустите файл `exe`

## Инструкция по управлению

* `W` / `Ц` — Движение вверх
* `S` / `Ы` — Движение вниз
* `A` / `Ф` — Движение влево
* `D` / `В` — Движение вправо
* `K` / `Л` — Быстрое сохранение (Quick Save)
* `L` / `Д` — Быстрая загрузка (Quick Load)
* `ESC` — Пауза / Выход из паузы
